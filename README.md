# Ambience

Text-to-ambience MVP: type a prompt ("rainy afternoon jazz…"), get back a structured
ambience (JSON) generated by a RAG + LLM pipeline, persisted locally or to an OCI bucket.

## Flow
```
User → Frontend → POST /ambiences {prompt, user_id}
     → AmbienceService → RAG+LLM (mock | Gemini Flash) → ambience JSON
     → persist (local files | OCI bucket) → 201 Created
```

## Architecture at a glance
- **Backend**: Python 3.12 + FastAPI. Thin controllers, services for orchestration.
- **Two replaceable "black boxes"** behind interfaces, swapped by config:
  - RAG-LLM pipeline (default `mock`, target `gemini`)
  - persistence (default `local`, optional `oci`)
- **Frontend**: vanilla HTML/CSS/JS (each view: own `.html` + `.css` + `.js`).
